صفحة متطلبات نقل الخدمة — لجنة تظلمات نقل الخدمة بمكتب عمل الرياض

الملفات:
- index.html: الصفحة الرئيسية الجاهزة للنشر عبر GitHub Pages.
- assets/mlsd.svg: نسخة منفصلة من الشعار المرفق. الشعار مضمن كذلك داخل الصفحة، لذلك لا يلزم الملف المنفصل لظهوره.

طريقة النشر:
1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع index.html إلى جذر المستودع مباشرة (وليس داخل مجلد فرعي).
3. افتح Settings ثم Pages.
4. اختر Deploy from a branch، ثم main والمجلد /(root)، واضغط Save.
5. انتظر ظهور رابط GitHub Pages وافتحه للتحقق.

مهم: يجب أن يكون اسم الملف index.html لكي تظهر الصفحة عند فتح الرابط الأساسي للمستودع.
